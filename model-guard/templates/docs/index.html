Safety principle

Uploaded model artifacts are treated as hostile data. ModelGuard validates extensions and sizes, computes SHA-256 hashes, inspects bytes and archive entries, and never deserializes or executes uploaded files. Executable demonstrations run only on reconstructed allow-listed scikit-learn models derived from validated descriptors and synthetic data.
