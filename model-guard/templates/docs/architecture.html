Assessment pipeline

  1. Validate extension, size and magic bytes; compute SHA-256.
  2. Store artifact; create ModelVersion and SecurityAssessment.
  3. Dispatch Celery task with in-process fallback.
  4. Run static byte/archive inspection and create evidence-backed findings.
  5. For validated descriptors only, rebuild an allow-listed estimator and run FGSM/PGD, SHAP and privacy indicators on synthetic data.
  6. Calculate risk score, persist results and enable PDF export.
